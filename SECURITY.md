# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitskorrekturen werden für die jeweils aktuelle veröffentlichte Version von Make:Log bereitgestellt.

## Sicherheitsproblem melden

Bitte Sicherheitsprobleme nicht als öffentliches Issue veröffentlichen. Nutze stattdessen die private Security-Advisory-Funktion des GitHub-Repositories. Beschreibe möglichst genau die betroffene Version, notwendige Voraussetzungen, reproduzierbare Schritte und die erwartete Auswirkung.

Veröffentliche Details erst, nachdem eine korrigierte Version bereitsteht und die Veröffentlichung abgestimmt wurde.
